기준 1.1 · 환자를 정확하게 확인하고 의사소통한다

📍 조사 장소

병동 의약품 투여 장소 검사실 외래 진료실 치료실 약제부서 회의실

👥 조사 대상

의사 간호사 약사 환자 확인 수행 직원 의약품관리 관련 직원
S
정확한 환자 확인 및 의사소통에 대한 규정이 있다
📋
규정 검토
환자 확인이 필요한 시점·수행자, 최소 두 가지 이상 지표 사용, 개방형 질문 포함 여부 / 구두처방 절차·필요시처방 목록 관리·혼동하기 쉬운 처방 유형 및 대처방안 포함 여부 확인
P
환자를 정확하게 확인한다
👁
의약품 투여·검사·처치 사례 직접 관찰
두 가지 이상 지표(성명+생년월일 등)를 사용한 환자 확인 절차 수행 여부 확인 / 병실 호수·위치를 지표로 사용하지 않음
💬
환자 확인 수행 직원 면담
의약품 투여·검사·처치 전 환자 확인 절차 및 인지 여부 확인 / 의사소통 어려운 환자(인지장애 등)에 대한 확인 방법 확인
P
구두처방을 정확하게 수행한다
📁
의사·간호사 관련 자료 확인
구두처방 상황 및 절차 확인(받아쓰기 → 되읽기 → 처방 확인) / 지정 시간 이내 처방 이행 여부 / 구두처방 사례 기록 확인
P
필요시처방(p.r.n)을 관리한다
📁
의약품관리 관련 직원 자료 확인
필요시처방 가능·불가능 처방 선정 및 관리 자료 확인 / 목록 점검 주기 및 최신화 여부 확인
P
필요시처방(p.r.n)을 안전하게 수행한다
📁
의사·간호사 관련 자료 확인
필요시처방 상황 및 내용 확인 / 필요시처방 사례 기록(의사 처방 → 간호사 수행) 확인 / 의무기록 내 처방 이행 기록 완비 여부
P
혼동하기 쉬운 부정확한 처방 시 대처방안을 알고 수행한다
💬
간호사·약사 면담
혼동하기 쉬운 부정확한 처방 시 대처방안 확인(수기처방 글씨체 문제, 전자처방 명확성, 유사코드·유사이름 의약품 확인)
✅ 준비 체크리스트
정확한 환자 확인·의사소통 규정 수립 (최소 두 가지 이상 지표, 구두처방·필요시처방·혼동처방 대처방안 포함)
의약품 투여·검사·처치 전 환자 확인 기록 완비 / 병실 호수를 확인 지표로 사용하지 않음
구두처방 사례 기록 및 지정 시간 이내 처방 이행 확인
필요시처방 가능·불가능 목록 최신화 및 관리 자료 완비
혼동 처방 유형별 대처방안 직원 교육 자료
의사소통 어려운 환자(인지장애·언어장애 등)에 대한 환자 확인 방법 규정 반영
🛡️
기준 1.2 · 낙상 예방활동을 수행한다

📍 조사 장소

병동 외래 진료실 검사실 치료실 이송 경로

👥 조사 대상

간호사 의사 의료기사 이송 담당 직원 환자·보호자
S
낙상 예방에 대한 규정이 있다
📋
규정 검토
낙상 위험 평가 대상·평가도구·평가시기, 고위험환자 예방활동, 낙상 발생 가능 장소별 예방활동 포함 여부 확인 / 요양병원 입원환자(노인·인지장애 환자 등) 특성을 반영한 고위험군 기준 명시 여부
P
낙상 위험 평가도구를 이용하여 환자 입원 시 초기평가를 수행한다
📁
간호사·관련 자료 확인
낙상 위험 평가 대상·평가도구·평가시기 확인 / 신뢰도·타당도가 입증된 도구 사용 여부 / 낙상 위험 분류 기준 확인
📁
입원환자 낙상 초기평가 의무기록 확인
입원 시 초기평가 기록 완비 여부 / 낙상 고위험 분류 환자 식별 기록 확인
P
낙상 위험 평가결과에 따라 고위험환자에 대한 낙상 예방활동을 수행한다 [필수]
👁
낙상 예방 환경·시설 관리 상태 관찰
침대 난간 사용, 미끄럼 방지 바닥, 야간 조명, 호출 벨 접근성 등 확인
💬
간호사·의사·의료기사·이송 담당 직원 면담
낙상 고위험환자 정보 공유 방법 확인 / 필요시 의학적·약학적 중재 수행 여부
👁
낙상 고위험환자 직접 관찰 (간호사 수행 활동 확인)
수행한 예방활동 내용(침대 난간 올림, 미끄럼 방지 양말 착용, 보조 기구 제공 등) 확인
🙋
환자·보호자 확인
낙상 예방 교육을 받았는지, 예방활동 내용을 인지하고 있는지 확인
📁
관련 자료 확인
낙상 고위험환자 예방활동 수행 기록 / 낙상 예방 교육자료(환자·보호자·직원용) 비치 여부
P
낙상 위험 평가도구를 이용하여 재평가를 수행한다
📁
간호사·관련 자료 확인
낙상 위험도 재평가 시점·절차 확인 (환자 상태변화, 낙상 발생 후, 정기 재평가 등)
📁
낙상 재평가 의무기록 확인
상태변화 시 재평가 이행 여부 / 재평가 결과에 따른 예방활동 변경 기록
P
낙상 발생 가능한 장소 또는 부서에서 낙상 예방활동을 수행한다
👁
직원 낙상 예방활동 직접 관찰
간호사·의사·의료기사·이송 관련 직원의 낙상 예방활동 내용 확인 (이동 시, 검사·치료 중 등)
💬
의료기사·이송 담당 직원 면담
이송 경로 및 검사·치료실에서의 낙상 예방 절차 인지 여부 확인
✅ 준비 체크리스트
신뢰도·타당도가 입증된 낙상 위험 평가도구 사용 (요양병원 노인 환자 특성 반영)
입원 시 초기평가 및 상태변화 시 재평가 기록 완비
낙상 고위험환자 정보 공유 방법 및 예방활동 수행 기록
낙상 발생 가능 모든 장소(이송 경로, 검사실, 치료실 포함) 예방활동 수행
환자·보호자 대상 낙상 예방 교육 실시 및 기록
침대 난간, 미끄럼 방지 시설, 야간 조명 등 낙상 예방 환경 점검

기준 1.3 · 손위생을 철저히 수행한다

📍 조사 장소

환자진료가 이루어지는 모든 장소 회의실

👥 조사 대상

환자 진료 관련 직원 감염관리 관련 직원
S
손위생 수행에 대한 규정이 있다
📋
규정 검토
손위생 수행 시점 5가지(환자 접촉 전·청결처치 전·체액 노출 후·환자 접촉 후·주변 기구 접촉 후), 올바른 방법, 소독제 종류 포함 여부 확인
P
손위생을 올바르게 수행한다
👁
직원 손위생 수행 관찰
손위생을 수행해야 하는 시점에서 직원의 손위생 수행 여부 확인 / 올바른 방법(비빔 시간, 전체 부위 등)으로 수행하는지 확인
💬
환자 진료 관련 직원 면담
손위생 5가지 시점 인지 여부 / 올바른 손위생 방법 숙지 여부 확인
P
손위생 수행을 돕기 위한 자원을 지원한다
👁
손위생 지원 자원 관찰
손소독제 구비 여부, 접근 용이한 세면대 설치, 환자·보호자용 손위생 수행 안내자료 비치 여부
📁
감염관리 관련 직원 자료 확인
손위생 수행을 돕기 위한 자원 지원 자료(소독제 구매·배치 기록, 직원 교육자료 등) 확인
✅ 준비 체크리스트
손위생 수행 시점 5가지 명시 규정 수립
올바른 손씻기·손소독 방법 규정 및 교육자료
환자 진료 장소 전체 손소독제 구비 및 세면대 접근성 확인
환자·보호자용 손위생 안내자료 비치
직원 손위생 교육 실시 및 기록 완비
의료기관평가인증원 인증기준 요약 대시보드
